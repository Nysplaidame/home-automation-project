    Connection tests and diagnostic console

    Tests run from VM103 using its system resolver and network access. A failed ping can mean ICMP is blocked; try the service’s TCP port too. Console output stays in this tab; bounded check summaries are retained in the incident timeline.

    Certificate checks cover Homepage, Home Assistant, Frigate and Vaultwarden using their own HTTPS hostname. Trust uses system roots and the Home Local CA. Renewal within 30 days or a legacy CA-format compatibility issue produces a warning; strict and legacy trust results are shown separately. This does not prove trust on your device.

    Run a guided check bundle

    These checks cover supporting connections. They cannot establish device operation, recording, backups, login or database health. They do not change imported route assessments.

    Choose a bundle to review its checks before running.

    Commands: ping TARGET, dns TARGET, tcp TARGET PORT, http TARGET, tls TARGET. Targets: proxmox, router, homeassistant, monitoring, docker, frigate, ai, nas, vault. Choose from listed ports. Each check is bounded; TLS checks use two handshakes.

          How do I get a health JSON file?
          
      On your Windows management workstation, open PowerShell in K:\Documents\Obsidian\home-automation-project and run:
      
          pwsh -File main/scripts/monitoring/health_check.ps1 -Full -Json > health.json
          
      Then choose Load health JSON and select health.json in that folder. Failed checks are useful evidence too: you can still load the file. The file stays in this browser.
      
          
      The full Windows check covers local/public DNS, trusted Homepage/vault HTTPS, Proxmox and APT-cache listeners, and Immich/Open WebUI endpoints, alongside the core checks. It does not log in, test uploads or prove database health.
      
          
      Use a new snapshot for the problem you are investigating. Files older than 36 hours, or without a timezone, cannot establish current health.
      
          
      For backups and recording mounts: collect JSON on the Proxmox host using the updated health collector. A Windows snapshot cannot supply those checks. Use the installed /usr/local/sbin/home-automation-dashboard-snapshot --json helper on Proxmox.
