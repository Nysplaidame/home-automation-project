ESP32 D1 Mini · feedback servo startup tests

Bench wiring based on the valve servo diagram. This version represents the newer connector board: no LED and no feedback resistor/capacitor network. Keep the horn disconnected from the valve and free of obstructions. Make wiring changes only with USB power removed. The orange plug is shown as two separate sides so the resistor location is unambiguous.

A · Floating-input baseline

Repeat of the existing control condition. Orange PWM is unplugged; the servo-side orange contact is insulated and floating. Record whether the horn advances on one power-up.

B · Isolated servo-side pull-down

Keep GPIO16 unplugged. Connect one 4.7–10 kΩ resistor from the servo-side orange signal contact to the same GND rail used by the servo brown lead. This tests whether a defined low input prevents the power-up movement without involving GPIO16.

C · GPIO16 connected with pull-down

Only after test B: reconnect GPIO16 while leaving the 4.7–10 kΩ resistor from the shared orange signal node to GND. This checks startup with the normal PWM connection. The resistor is across signal and ground, not in series with orange.

Use one configuration at a time. A result from B is the most useful: if the horn still advances with GPIO16 unplugged and its own signal input pulled low, GPIO16 startup behavior is not the cause. Do not attach the valve linkage during these tests. No pull-up test is included because the reported 5 V pull-ups are unsuitable for a connected ESP32 GPIO.
