# Memex

## Definition

The founding methodology names Vannevar Bush's Memex (1945) as an ancestor
of a personal curated knowledge store with associative trails. This page records
that attribution from the idea file; it is not a project software component.
[[sources/llm-wiki-idea-file]]

## Relevance to this project

The analogy motivates linked sources and maintained synthesis in the wiki.
It does not establish a deployed tool or alter project authority.
