# GL.iNet GL-MT6000

**Type:** device — router / firewall
**Status:** ✅ Owned / ⏳ Not yet deployed (on existing flat network)
**Related:** [[concepts/vlan-segmentation]], [[concepts/wireguard-vpn]], [[entities/home-assistant]], [[entities/ventsys]]

## Overview

WiFi 6 router running OpenWrt (DSA), serving as the network core for the entire home automation system. Implements the 9-VLAN security-segmented architecture. All configs written; deployment pending.

## Key Properties

- Platform: OpenWrt (DSA — Distributed Switch Architecture)
- Ports: 4× GbE LAN + 1× WAN
- WiFi: WiFi 6 (802.11ax), dual-band
- WireGuard: built-in support (VLAN 70 / DMZ)

## Port Assignments

| Port | Role | VLAN |
|---|---|---|
| lan1 | Trunk → MINIX Proxmox | Tagged: 10,20,30,40,50,60,70 |
| lan2 | Management access | VLAN 10 untagged (PVID) |
| lan3 | Camera PoE switch | VLAN 30 untagged (PVID) |
| lan4 | Pi NAS direct | VLAN 40 untagged (PVID) |
| lan5 | **Recovery / TP-Link AP** | VLAN 1 untagged (PVID) |

> **lan5 notes:** Connect laptop here before Phase 2 of router setup for guaranteed SSH access to 192.168.1.1 regardless of VLAN misconfiguration. After setup stabilises, connect TP-Link TL-WA801N AP (bridges HomeMain WiFi to VLAN 1 wired). No config changes needed when transitioning from recovery use to AP use.

## WiFi SSIDs

- **Main / users:** VLAN 1
- **HomeIoT:** VLAN 50 (2.4GHz only, CH6, WPA2, client isolation, 15dBm)
- **Guest:** VLAN 99

## Config Files

All in `home-automation-safety/configs/openwrt/`:
- `vlan-config.conf` — VLAN bridge, logical interfaces, WireGuard
- `firewall-config.conf` — zones, inter-VLAN rules, VentSys ports
- `dhcp-config.conf` — DHCP scopes, static reservations, DNS
- `wireless-config.conf` — SSIDs, channels, WPA3/WPA2

## Key Firewall Rules (summary)

- IoT (VLAN 50) → HA (VLAN 20) port 8883: ALLOW (MQTT TLS)
- IoT (VLAN 50) → WAN: DENY + log
- IoT (VLAN 50) → Router port 123: ALLOW (NTP)
- CCTV (VLAN 30) → WAN: DENY
- HA (VLAN 20) → CCTV: ALLOW (Frigate access)
