# GL.iNet GL-MT6000

**Type:** device — router / firewall
**Status:** ✅ Owned / ✅ Deployed and stable
**Related:** [[concepts/vlan-segmentation]], [[concepts/wireguard-vpn]], [[concepts/tailscale-remote-access]], [[entities/home-assistant]], [[entities/ventsys]], [[entities/monitoring-vm]], [[entities/docker-host]], [[entities/adguard-home]]

## Overview

WiFi 6 router running OpenWrt (DSA), serving as the network core for the home automation system. It implements the 10-VLAN security-segmented architecture. Router configs are deployed via `tools/router-deploy`; the router is stable on management IP `192.168.10.1`.

The router currently piggy-backs the existing home router for internet via a WiFi uplink as a temporary staging path. The final architecture will eventually make this router the internet edge.

## Key Properties

- Platform: OpenWrt (DSA — Distributed Switch Architecture)
- Management IP: `192.168.10.1` (VLAN 10)
- Ports: 5× GbE LAN + 1× WAN
- WiFi: WiFi 6 (802.11ax), dual-band
- WireGuard: built-in support (VLAN 70 / DMZ)
- Deploy tool: `tools/router-deploy/` (first-flight applied, full profile pending)

## Port Assignments

| Port | Role | VLAN |
|---|---|---|
| lan1 | Trunk → MINISFORUM Proxmox | Tagged: 10,20,30,35,40,50,60,70 |
| lan2 | Management access | VLAN 10 untagged — physically validated |
| lan3 | Live GS1900 switch trunk | Tagged: 1,10,30,40 — cameras on ports 2-4 and OMV on port 8 |
| lan4 | Storage recovery/access | VLAN 40 untagged — normally unplugged |
| lan5 | LAN / recovery | VLAN 1 untagged — user/recovery access |

## WiFi SSIDs

- **HomeMain** — VLAN 1 (main users)
- **HomePrinters** — VLAN 35 (printer OTA/LAN)
- **HomeIoT** — VLAN 50 (2.4GHz, client isolation)
- **HomeGuest** — VLAN 99
- Plus management/monitoring SSIDs as defined in `wireless-config.conf`.

## Config Files

All canonical files in `main/configs/openwrt/`:
- `vlan-config.conf` — VLANs 1/10/20/30/35/40/50/60/70/99.
- `firewall-config.conf` — zones and inter-VLAN policy.
- `dhcp-config.conf` — scopes and static reservations.
- `wireless-config.conf` — SSIDs and radio settings.

Deployment toolkit: `tools/router-deploy/` (lint, compile, deploy, test scripts).

## Live Firewall / Policy Notes

- Temporary rule `TEMP Docker Host Update Access` was removed after Docker/Bambuddy pulls and apt-cache validation.
- `apt-cacher-ng` on docker-host is reachable from `frigate-nvr` via permanent `Frigate to APT Cache` rule.
- Router DNS targets [[entities/adguard-home]] on docker-host first, with Quad9/Cloudflare public fallback.
- docker-host has narrow permanent egress for Tailscale, AdGuard and Mullvad
  WireGuard. The host-specific `Docker Host VPN Egress` rule includes UDP
  `51820`; general Docker pulls remain maintenance-window actions.
- Router-local NTP server is enabled, with UDP/123 input rules for restricted VLANs that need local time.
- OpenWrt forwards syslog to monitoring VM (`192.168.60.10:514/udp`).
- Router/source parity has been cleaned up: no valve-specific plain-MQTT `1883` exception is treated as current. VentSys MQTT traffic should use TLS `8883`; any plaintext bootstrap exception must be explicitly temporary and documented before use.
- The canonical 48-entry `home.local` domain inventory is live in dnsmasq and passed full source/service-matrix/router resolution validation on 2026-07-29.
