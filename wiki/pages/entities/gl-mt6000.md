# GL.iNet GL-MT6000

**Type:** device — router / firewall
**Status:** ✅ Owned / ✅ Deployed and stable
**Related:** [[concepts/vlan-segmentation]], [[concepts/wireguard-vpn]], [[entities/home-assistant]], [[entities/ventsys]]

## Overview

WiFi 6 router running OpenWrt (DSA), serving as the network core for the entire home automation system. Implements the 10-VLAN security-segmented architecture. All configs written and deployed via `tools/router-deploy` first-flight. Router is stable on management IP 192.168.10.1.

The router currently piggy-backs the existing home router for internet via a WiFi uplink (temporary staging path). The final architecture will make this router the internet edge.

## Key Properties

- Platform: OpenWrt (DSA — Distributed Switch Architecture)
- Management IP: `192.168.10.1` (VLAN 10)
- Ports: 5× GbE LAN + 1× WAN
- WiFi: WiFi 6 (802.11ax), dual-band
- WireGuard: built-in support (VLAN 70 / DMZ)
- Deploy tool: `tools/router-deploy/` (first-flight applied, full profile pending)

## Port Assignments

| Port | Role | VLAN |
|---|---|---|
| lan1 | Trunk → MINIX Proxmox | Tagged: 10,20,30,35,40,50,60,70 |
| lan2 | Management access | VLAN 10 untagged — physically validated |
| lan3 | Camera / NVR | VLAN 30 untagged — DHCP/ping validated |
| lan4 | Storage / NAS | VLAN 40 untagged — DHCP/ping validated |
| lan5 | Recovery / TP-Link AP | VLAN 1 untagged — LuCI/DHCP validated |

## VLAN Architecture (10 segments)

| VLAN | Name | Subnet | Internet |
|---|---|---|---|
| 1 | LAN (users) | 192.168.1.0/24 | ✅ |
| 10 | Management | 192.168.10.0/24 | ✅ |
| 20 | Automation (HA) | 192.168.20.0/24 | HA only |
| 30 | NVR (Frigate) | 192.168.30.0/24 | ❌ |
| 35 | Printers | 192.168.35.0/24 | OTA only |
| 40 | Storage (NAS) | 192.168.40.0/24 | ❌ |
| 50 | IoT sensors | 192.168.50.0/24 | ❌ |
| 60 | Monitoring | 192.168.60.0/24 | Limited |
| 70 | DMZ / VPN | 192.168.70.0/24 | Limited |
| 99 | Guest | 192.168.99.0/24 | ✅ |

## WiFi SSIDs (6 configured)

- **HomeMain** — VLAN 1 (main users)
- **HomePrinters** — VLAN 35 (printer OTA/LAN)
- **HomeIoT** — VLAN 50 (2.4GHz, client isolation)
- **HomeGuest** — VLAN 99
- Plus management and monitoring SSIDs
