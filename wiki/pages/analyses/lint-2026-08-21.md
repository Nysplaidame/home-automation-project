# Analysis: Mobile Homepage proxy and Tailscale access lint

**Query:** Do the wiki pages reflect the canonical 2026-08-21 mobile Homepage
access model?
**Date:** 2026-08-21

## Answer / Findings

- [[entities/homepage]], [[entities/docker-host]], and
  [[concepts/tailscale-remote-access]] now consistently state that mobile
  application access uses only the fixed Homepage HTTPS proxy routes, not a
  broad private-subnet route.
- The approved OnePlus identity is limited to Docker-host DNS, `tcp:443`, and
  `tcp:8180-8209`. Recomp Tracker's fixed proxy is `8209`.
- Home WiFi remains a separate LAN DNS path, so the same Homepage URLs work
  with Tailscale off. Mobile data requires Tailscale; no public exposure was
  introduced.
- The changed entity pages link to each other and to the remote-access concept;
  the analysis is indexed and logged.
